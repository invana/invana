Small talk offers what to ask next (NL14). After *hi* or *what can you do?* the assistant's reply is followed by up to three questions drawn with the choice template; tapping one asks it. A thanks or a goodbye gets the reply alone.

Every choice is one the run could answer: each names the types it reads, and it is kept only when the run's world lets it read them, the agent may run a query and the world lets it read the graph at all. Under a world that shuts everything, the reply comes with no choices. Only the latest turn's choices can be tapped, and they survive a reload.
