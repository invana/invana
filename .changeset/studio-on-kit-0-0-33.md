Studio runs on design-kit 0.0.33 and canvas 0.0.15. A run's and a plan's Layers tab is now a gantt: a row per layer that opens into its participants, with one bar per touch (or per declared step for a plan). A refusal is a struck bar. The run's Layers tab always fits its panel, so the `Fit` switch is gone. Board tiles, record panels and tables use the kit's block panels, and picking a row in a table or a gantt still opens what it did before (SR21 · SR69 · SR73 · SR74 · LB31).
