A skill's plan comes only from its words, and a sentence composes a library plan by naming it.

- The planner reads the Graph's reusable library plans beside the catalogue. A sentence such as *Answer it with nl-single, writes allowed* draws that plan's rows in: copied flat, each saying which plan and step it came from, with the arguments the sentence sets. An argument the plan does not declare, or a plan the Graph does not offer, refuses the draw and names it.
- Removed: `PATCH …/skills/{id}/draft/tasks` (the hand-edit), `GET …/skills/inlinable` (its picker), and `vocabulary` on the draft read. Nothing new is written with origin `authored`; rows written before read as they are.
- Studio: the skill's flow is read-only. *Edit by hand* and the *Discard and redraw* confirmation are gone; *Redraw* replaces the plan with what the prose reads as.
- A draft opened over a published version keeps the library plans that version composed.
