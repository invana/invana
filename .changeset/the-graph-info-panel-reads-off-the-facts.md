The graph info panel reads off the facts

Setup progress is derived from the Graph rather than a checklist someone has to
tick: a step is done when the thing it asks for exists — a connection is
attached, the instructions are written, a skill is defined, an import run
succeeded. Importing data used to leave "Imports" reading as untouched.

The Info section is the **graph info panel** now, and carries three bands:
the graph's identity, the setup timeline while setup is unfinished, and the
recent sessions. The three number cards (LLM providers · Skills · Members) are
gone — each has its own panel a click away. A session row opens that session in
the assistant.
