A world that names a model narrows with it — and names its stitches too.

A run is grounded on the introspected `global` model, because it is the one model whose types cover
what an arbitrary query can reach. Every world in the demo names the **authored** models instead, so
its rules matched an address no run ever engages: `Deals@*` froze into the snapshot and narrowed
nothing, and a world that closed `graph_data` refused every read as *cannot answer*. A bound that
fails **open** while looking closed, and a bound that refuses everything, from the same gap.

[GV33] closes it. A rule naming a published version now resolves to the node and edge types **that**
version declares, applied to the version the run is grounded on and sliced along **that** model's
axes — the mirror declares none, so a slice resolved against it compiled to nothing. `open_graph`
compiles before it decides, so closing `graph_data` and naming four models is a bound rather than a
refusal; only a closed-layer refusal is rescued, because a rule that denies the grounding version by
name still wins. Narrowing accumulates where two models declare one type: exclusions union, selects
merge, and a denial either side denies the type.

**The stitches had to come with them.** An edge that crosses two models belongs to neither, so a
world naming all four of a Graph's models still could not traverse between them — ten crossing edge
types fell through to the grounding version and the closed layer left them out. A stitch is its own
participant, so it is its own binding, bounding the one edge type it writes. *EU · H1 2026* names
`graph_data/stitch/**` beside its four models, which takes it from 34 of 44 types in view to all 44.

**The catalogue was offering stitches nothing could engage.** It filtered on the link's own status
and not on its endpoints', so a model that republishes left its old stitches behind, bound to
archived versions — and that is the second way two rows collide on one address, since the address
carries no version and a re-declared stitch lands on its predecessor's name. Both are gone by
requiring both endpoint versions active.

**A world that cannot open now actually says so.** The chip skipped every rule whose match contained
a `*`, and `Deals@*` is the form the picker teaches — *every published version, survives the next
publish* — so the check exempted almost every world anyone authors and refused nothing. It resolves
wildcards like any other pattern now, reading `graph_data/model/…` rules alone: a layer with nothing
configured is not a stale world.

What bound a read is recorded on the touch, so a run can still answer *what narrowed me* after one
of those versions is archived.
