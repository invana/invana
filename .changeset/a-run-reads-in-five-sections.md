A run drilled into from Runs reads in five sections (SR67).

`The run` (what was asked, the query that ran, plan, agent, the lens as a link into Govern, who opened it, elapsed) · `What it cost` (spend against the per-run
ceiling, tokens, and time spent waiting rather than working) · `What it touched` (one line per layer,
a refusal struck, an untouched layer dimmed) · `Bounds reached` (rounds, attempts, replans against
their ceilings) · `Refused` (each denied address and why). The header reads `run:7d3184f1` with its
status and how much of it was work. `Open the answer` opens the run page; `Compare with the plan`
draws the Library plan it ran beside it.

`GET …/runs/{id}/trace` now carries `triggered_by`, `opened_by`, `clarifications`, `replans` and `lens_ref`, and
each step its `max_attempts`.
