A model opens as a board named for itself, and the board actually draws it.

Drilling into a model already opened its canvas beside the detail; the tab over it read `Model`, and the canvas was blank. Both are fixed.

**The tab is named for the model.** `AirRoutes`, never `Model` — the rule a lens board already follows. Two models open side by side put two tabs on the strip, and a strip reading `Model · Model` is one a reader has to click through. The name comes off the models list the panel has already read, so it costs no request.

**The drawing is installed before the camera frames it.** A layer holds every node invisible while a declared layout has yet to report a run, so an unplaced node never paints at the origin. The model sim runs un-animated and settles in the same beat as the data it is laying out, so that gate lifted against a flush that had already been and gone and the drawing was never installed — the store held the four types, the minimap drew them, and the viewport stayed empty. The bridge that frames the settled solve now redraws the layer first: a pure render pass over what the store already holds.
