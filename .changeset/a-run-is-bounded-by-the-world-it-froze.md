A run is now bounded by the world it was asked under, not only labelled with it.

Before it engages a participant, a run checks the address against the lens it froze at open. A model
or a model version the world denies ends the run in *cannot answer* naming the rule it was refused
by — the run succeeds with a refusal rather than erroring, because a bound doing its job is not a
fault. The narrowing reaches the graph database as a predicate composed into the query and a
projection rewritten to the properties this world carries, never as a filter over rows that already
came back. What may accompany a call across the boundary is cut out of the prompt's parts before the
prompt is built, and both halves are recorded: what crossed, and what did not.

Every engagement now writes one entry to the run's ledger, and the run dashboard's six-band strip,
*This run's lens*, the per-step *generated vs executed* digests and the two-run comparison all read
real data for the first time. A Task's run, a skill draw and a re-run freeze their lens at open like
a question does, so the bounds hold however a run starts; a re-run whose world has since been
deleted is refused rather than quietly re-run wide.
