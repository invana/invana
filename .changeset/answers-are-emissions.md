An answer is its emissions, and every one of them wears the same card.

**A result is no longer a bare table under the reply.** It goes through the emission card the hi-fi draws: a 24px header — `kind` · `template@version` · `cite · N records` — over a body chosen by the kind. The header is one component wherever an emission appears, so a task result and a scheduled answer will read exactly like the thread does. It names a template only when a projection chose one; nothing is defaulted in to make the row look complete, because a template nobody chose is a claim about how the answer was rendered that isn't true yet.

**Zero records is an answer now, not a blank.** A query that returns nothing used to render nothing at all — the reply's `Returned 0 rows.` was the whole surface. The empty emission says what the graph does not hold, in the reading order, where the answer would have been.

**A subgraph says what it did to the canvas.** Once a graph result is painted, the thread carries `9 nodes · 12 edges added to the canvas — nothing replaced` on the emission's own line, in place of the `you loaded this to canvas` sub-line. The offer before it lands is unchanged. What a subgraph *adds* is the fact worth stating: it never replaces what is already there.

**`metric`, `chart` and `prose` are drawn ahead of the engine.** Nothing produces them yet — the project step still emits a query result — and they are built now because the answer surface is the one place Studio leads, and the design system blocks on the components they name.

**A stream frame is not an emission.** The two had the same name on both sides of the wire, which made "emission" mean the thing travelling *and* the thing read. A **thought frame** is how anything travels — a step transition, a diagnosis, an emission arriving; an **emission** is the produced answer part. `stream.Emission` is `stream.Frame` in the engine, `Emission` is `ThoughtFrame` in Studio, and the word is free for what a reader sees.

**The ask-mode switch has a name.** `Natural Language` / `Query Language` was a control whose only text was its current value — unreadable to a screen reader, which reads it as an unlabelled combobox next to another one. It is now labelled `Ask mode`, the way the timeout select beside it already was.
