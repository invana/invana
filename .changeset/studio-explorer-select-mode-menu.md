Move the Explorer selection-mode picker into the canvas context menu.

The **click / brush / lasso** selection modes are no longer a dropdown in the
Explorer header toolbar. They now live under a **"Select mode"** submenu in the
canvas (background) right-click menu, with one sub-item per mode — the active
mode is ticked, and choosing one arms that drag-select behaviour. This declutters
the header and keeps the mode switch where the selection happens.
