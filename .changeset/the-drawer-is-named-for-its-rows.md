The Agents stack's top drawer is `Agents`, and *roster* is retired (AG12 · G33).

A drawer is named for the rows it holds, and the rows are agents. Every other stack already reads
that way — `Projects` › `Projects` · `Todos`, `Skills` › `Skills` · `Rules`, `Govern` › `Worlds` ·
`Guardrails` — and the Agents stack was the one that named its table instead of its rows.

The word is gone, not just the label: the drawer id is `agents` (`?panel=agents&drawer=agents`), the
component is `AgentsDrawer`, the feature file is `author-an-agent.md`, its decisions are `AG1…AG12`,
and the engine and Studio comments say *the agents* or *the list*. An old `?drawer=roster` link
still lands on it — an unknown drawer falls to the first one, and this is the first one.

*Roster* was also doing a second job: the set of skills an agent carries. That is **bindings**,
which is what `skill_bindings` has been called since it became a row. One word naming two things is
one word too many.
