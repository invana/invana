Studio re-runs a run and shares an answer (pinned-model-versions.md, share-an-answer.md).

- **Re-run** — a settled question or query's run page carries *Re-run…*. The dialog names what the run
  ran with — the exact model version, the agent, the world — and re-runs it on **the same versions**, to
  reproduce it, or on **current versions**, to compare. The new run opens on its own page; a re-run on
  current versions opens the comparison when it finishes, and every re-run offers *Compare with the
  original*. A version the Graph no longer offers is refused by name.
- **Share an answer** — *Share* on an answer's reply line copies a **live link** (the same board and
  chat) or keeps a **frozen snapshot** (the board's records, the answer, its citations and the dataset
  versions bound at the time) and copies its link; both open only for the Graph's members. Anyone else
  gets a file: the board as **PNG**, the answer's rows as **CSV**, or the whole answer as **Markdown**.
