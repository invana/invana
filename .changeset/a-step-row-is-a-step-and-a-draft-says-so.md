A step row is a step, and a draft's board says what it has instead of what it lacks.

The three Skills boards were built, typed and never opened. Clicking them found four things.

**Recent steps drew fewer rows than the engine sent.** The list keyed each row by its run, and two
steps of one run — one offered, one applied — are two rows with one key, which React collapses. A
row is a step, so its id is the step's; the page reads the run back out of the document it drew,
and a step whose root run is gone carries no action rather than an action that opens nothing. The
rule board's **Where it was cited** had the same key and the same fix.

**A draft's board said three things that were not true of a draft.** *Offered on every ask* is what
a blank trigger means once published; *something wrote a version without drawing it — which the
engine does not allow* is a fault report, and a draft is not a fault; and **Per version** drew
column headings over no rows. The board now says *nothing published yet* in each place, the version
chip reads `draft` rather than `v0`, and *an earlier text* is absent instead of claiming the reader
moved off a version that does not exist.

**The Usage tab's own `More`** now opens the usage board, which the design has said all along. It
sits in the tab rather than in the panel header: a header action that changed meaning with the
selected tab would be two actions wearing one icon.
