Explorer: drop into the new session immediately, with run progress and a stop control.

Sending a query from the sessions list now opens its thread right away — the prompt and a "Running query…" indicator (animated dots) appear instantly instead of leaving you on the list until the engine responds. While a run is in flight the composer's send button becomes a stop button; clicking it cancels the in-flight request and the thread marks that turn as stopped.
