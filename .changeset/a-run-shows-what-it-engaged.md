A run shows what it engaged, one step at a time, and two runs can be put side by side (R1 · R2 · R3 · R4).

**The run dashboard gains two bands**, both registry panels owned by the Govern feature module so
Operate hosts them without owning what a touch means. `What each step engaged` is the six-band strip
— steps as columns, layers as bands, **refusals struck in place** so `seq` order still reads and a
cell cannot be mistaken for a step that never got there; a layer nothing touched renders **dark, not
hidden**, because *the run never went near a third party* and *this surface does not show third
parties* are different facts. `This run's lens` is **allowed · touched · refused**, and the
difference between the three is the whole panel: allowed and never touched, run after run, is
*narrow*; refused repeatedly is *widen, or accept cannot answer deliberately*. `Retune` opens Govern
beside the run without closing it.

**A step says what was asked for and what actually ran.** The generated and executed query digests
sit side by side, and their differing *is* the lens being composed into the query rather than rows
being filtered after they came back. The slice that was applied, the volume, and what egress cut are
read under the output they produced.

**Compare is a page**, `compare:<a>:<b>`, reached by `Compare…` on a finished run
([WO13](docs/for-developers/modules/govern/features/worlds.md)) — runs that asked the same question
come first, because *one question, two worlds* is the pairing the design is about. What B touched
that A did not is the only part a person cannot reconstruct by reading both answers, so it leads;
*both touched exactly the same things* is a real result and says so in a sentence rather than as an
empty list.

**A lens reads back with its cast resolved and checked** — *innermost wins, then the address is
checked against the effective rules*. A role cast to a model a guardrail denies comes back denied,
naming the rule, on the surface where the person who can fix it is reading — not as a row that looks
fine until a run refuses to open.

**Every one of these renders its *nothing recorded* state honestly** while `run_touches` has no
writer: an empty grid would say the run touched nothing, which is a different claim.
