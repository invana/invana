Invana now names itself one way: **an ontology-governed operating system for humans and AI agents**.

The package description, the `invana` CLI help, the API description and the docs site carry it in place of *Graph
Intelligence Platform*. Studio's sign-in page reads the tagline — **One knowledge graph, one set of rules, for every
thinker — human or AI** — and the Graphs list drops its tagline. The simulations docs page now describes what ships —
a simulator plugin run on a project branch over pinned dataset versions — and lists game theory and parameter sweeps as
after 1.0.
