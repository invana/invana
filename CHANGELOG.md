# Changelog

All notable changes to Invana are recorded here. This file is the changelog —
the website links to it rather than keeping a copy, so the record cannot drift
from the code it describes.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
Invana follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Categories used per release: **Added · Changed · Deprecated · Removed · Fixed ·
Security**. One line per change, written for someone deciding whether to
upgrade — not a commit dump.

## [Unreleased]

Nothing released yet. Invana is pre-1.0 and pre-launch: the repository is public,
the version is `0.0.0`, and no tag has been cut. The first entry here will be the
first tagged release.
