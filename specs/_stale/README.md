# Stale — not live

> **Not live.** Nothing here is a spec, a decision or a plan anyone works from. Never read it, cite it or link to it
> from a live spec, doc or code. Each file is deleted one release after it landed here unless someone pulls it back —
> by writing what it still holds into the live spec or doc that governs it.

| | |
|---|---|
| What | Docs and plans the M3 audit found superseded, retired or placeholder |
| Layout | Each file keeps its original path under `specs/_stale/` — `docs/products/iam.md` is `specs/_stale/docs/products/iam.md` |
| Live home | `specs/` (`README.md`, `vision.md`, `system-design/`) and `docs/` |
| Code | [`code.md`](code.md) lists each code path the audit deletes, and why |
| Pull one back | Write its content into the live file that owns it, in that file's format; never move it back as is |
