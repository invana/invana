Start from what the person wants the data to describe, and search the web for a source that publishes it.
Prefer an official or primary source — a government portal, a registry, the project that maintains the data — over a page that copies it.
Read the most promising result before trusting it, and check that it really holds the data asked for and says where the file is.
When the page links a downloadable file — CSV, JSON, a zip of them — download and extract that file rather than reading the data off the page.
Keep the download within its size limit; if the source is larger, say so and ask whether a smaller part will do.
When the data only exists as text on pages, read each page and take the rows from what it says.
If robots.txt refuses a page, leave it and look for another source — never work around the refusal.
Keep every row's source URL with it, so anything built from the data can say where each row came from.
Report what was collected: the sources used, the files read, how many rows each gave, and anything that was skipped and why.
If no source holds the data, say so plainly rather than assembling something that looks like it.
